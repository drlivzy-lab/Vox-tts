# Дословная проверка аудио: какие модели и зачем

Задача: услышать, что **на самом деле** прозвучало, включая повторы, заикания, обрывы и лишние слова,
и сравнить с отправленным текстом. Обычные распознаватели для этого плохи: они обучены выдавать
«чистый» текст и сглаживают как раз то, что мы ищем.

## Рекомендуемая связка

| Роль | Модель | Где | Почему |
|---|---|---|---|
| Основная | **GigaAM-v3 CTC** (`qc.asr = "gigaam"`) | локально, CPU/GPU, MIT | лучший открытый русский ASR (WER 9,2% против 25,1% у Whisper-large-v3 на тестах Сбера); CTC-декодер выдаёт звучащие токены без языковой «доводки», поэтому повторы и оборванные слова остаются в тексте |
| Вторая, независимая | **Gemini 3.8 Flash** (`qc.second_asr = "gemini"`) | облако, тот же ключ | стенограмма по инструкции «дословно, с повторами и заиканиями» + список аномалий: заикание, смена тембра, неверное ударение, озвученная разметка. Ловит то, что не выражается словами |
| Слух | человек | — | ударения, тембр, актёрская игра. Две модели не доказывают правильность ударения |

Почему не Whisper: seq2seq-модель склонна выбрасывать повторы и оговорки, а иногда дописывает несказанное.
Если он всё же нужен, используйте `faster-whisper` с `large-v3`: харнесс подаёт ему затравку с оговорками,
которая подталкивает к дословности. Но это запасной вариант.

**CrisperWhisper 2.0** (nyralabs) специально обучен на дословную расшифровку: заполнители, повторы, заикания,
точные таймкоды слов. Но русский официально не заявлен, а лицензия **некоммерческая**: для рекламы компании
нужна коммерческая. Подключать только после проверки на ваших записях и при наличии лицензии.

## Установка

```
pip install git+https://github.com/salute-developers/GigaAM      # GigaAM (torch подтянется сам)
# в book.toml:
[qc]
asr = "gigaam"
asr_model = "v3_ctc"        # или v3_rnnt (точнее, чуть менее «буквальный»)
second_asr = "gemini"       # необязательно, платно (≈32 токена ввода на секунду аудио)
gemini_model = "gemini-3.8-flash"
```

Для GigaAM аудио режется на окна до 20 с по самым тихим местам (модель рассчитана на короткие фрагменты).
Таймкоды слов приблизительные, с точностью до окна. Gemini получает файл целиком (до 18 МБ, то есть
до ≈6 минут WAV 24 кГц) и возвращает сегменты с MM:SS.s.

Стоимость Gemini-проверки: аудио на входе считается как 32 токена в секунду, то есть ≈115 тыс. токенов
на час. Итоговая цена зависит от тарифа аудиовхода `gemini-3.8-flash` (сверьте на странице цен) и обычно
ниже стоимости самой озвучки. Для экономии включайте её выборочно: `qc run --sections …`.

## Что считается сигналом

`qc run` сравнивает отправленный текст (с IPA, обратно заменённой на слова) с расшифровкой каждого движка:

| Сигнал | Условие |
|---|---|
| лишние слова | вставка ≥ 4 слов (`qc.insert_min_words`) |
| пропуск | потеряно ≥ 4 слов |
| повтор | фраза из ≥ 4 слов прозвучала дважды, а в тексте она одна |
| обрыв конца | последних слов текста нет в конце записи |
| повтор на стыке | начало запроса повторяет конец предыдущего |
| аномалия: … | из списка аномалий Gemini |
| техника | пустой файл, клиппинг, скорость речи вне 7–28 символов/с, пауза внутри > 2,5 с |

Всё это **кандидаты**, а не доказанные дефекты. Решение принимает слушатель (`qc accept` / `qc reject`).
Авторские повторы, которые есть в тексте, сигналом не считаются. Две расшифровки одной моделью
независимой проверкой не являются: для этого и нужен второй движок другой архитектуры.
