# Как писать сценарий для Gemini 3.8 Flash TTS

Это руководство для агента и человека, которые готовят текст к озвучке: книги, рекламу, слоганы,
голос для рилсов. Технический справочник модели — [GEMINI_TTS.md](GEMINI_TTS.md).

## Главный принцип

Модель читает **ровно** то, что стоит в `text`. Всё остальное (кто говорит, как, зачем) идёт в поля:
`speaker_id`/`voice` — кто, `style` — как, `mode` — в каком режиме. Текст должен звучать естественно,
если его прочитать вслух дословно.

## Формат блока

```
### s004-0012

```yaml
source_ids: [p000491]      # (книга) из какого абзаца
scene_id: s004-sc02        # (книга) сцена: смена сцены = длинная пауза
speaker_id: SIRI           # роль из cast.json  | для клипа: voice: Kore
mode: spoken               # narration|spoken|thought|written|heading|epigraph|mouthed|skip
style: "Quietly insistent."
confidence: high           # (после ИИ) high|medium|low
pause_after_ms: 800        # (необязательно) точная пауза после блока при монтаже
review_status: draft       # approved — после вычитки
```

```text
Ты хочешь уйти <short pause> именно СЕЙЧАС?
```
```

## Режимы (mode)

| mode | Кто читает | Как звучит в монтаже |
|---|---|---|
| narration | рассказчик | сухо |
| spoken | персонаж | сухо |
| thought | персонаж, сдержаннее | лёгкая реверберация (`[effects.thought]`) |
| written | автор письма или записки, спокойно | сухо |
| heading, epigraph | рассказчик | пауза после заголовка |
| mouthed, skip | никто | не озвучивается (паузы сохраняются) |

## Словарь подачи

Короткие английские фразы, проверенные на русской речи или рекомендованные Google. За одну пробу меняйте
только один фактор. Одинаковую подачу повторяйте дословно.

| Нужно | style |
|---|---|
| нейтрально | *(пусто)* |
| тихо, но разборчиво (вместо шёпота) | `Speak quietly in a voiced tone, with clear articulation.` **[проверено]** |
| шёпот (коротко, по делу) | `A hushed whisper.` (разборчивость хуже) |
| медленнее | `Read at a leisurely pace.` |
| быстрее | `Deliver the line briskly.` |
| громко, зовёт | `Call out loudly with urgency.` |
| сдержанный гнев | `Restrained anger, clipped delivery.` |
| сарказм | `Dry, understated sarcasm.` |
| страх | `Frightened, with a trembling delivery.` |
| печаль | `A subdued, sorrowful delivery.` |
| радость | `Sound delighted by the news.` |
| сомнение | `Hesitant and uncertain.` |
| уверенность | `Measured, assertive delivery.` |
| бормотание | `Murmur under your breath.` |
| запыхался | `Breathless after running.` |
| ровно, без эмоций | `Keep the intonation deliberately flat.` |
| чёткая дикция | `Articulate each word distinctly.` |
| реклама, тепло | `Warm, friendly, a smile in the voice.` |
| реклама, энергично | `Upbeat and energetic, punchy delivery.` |
| премиум, доверие | `Calm, confident, premium; unhurried with gentle authority.` |
| хук для рилса | `Intriguing, conspiratorial, leaning in close.` |
| призыв к действию | `Clear, inviting call to action; slightly faster at the end.` |
| дисклеймер | `Neutral and brisk, clearly articulated.` |

Не пишите в style: возраст, пол, тембр, акцент, имя, «тот же голос, что раньше». Это свойства голоса,
и такие пометки только усиливают дрейф.

## Теги и акценты

- Теги ставьте только из таблицы в GEMINI_TTS.md §6, по-английски и в `< >`: `<sigh>`, `<laugh>`,
  `<short pause>`… `vox check` и `clips plan` остановят всё остальное.
- Тег должен быть оправдан текстом («вздохнул» → `<sigh>` в реплике персонажа). На абзац — не больше 1–2.
- Логический акцент — ВЕРХНИЙ РЕГИСТР одного слова: «Я сказал ЗАВТРА, а не сегодня».
- Точные паузы (рекламная пауза перед ценой, 1,2 с перед финальной фразой) задаются через `pause_after_ms`
  или отдельным блоком, а не цепочкой тегов.

## Текст для уха

- **Числа, даты, цены, телефоны — словами и в нужном падеже**: «двадцать пятого марта»,
  «девятьсот девяносто девять рублей», «восемь, восемьсот, пятьсот…». Цифры модель склоняет ненадёжно.
- Сокращения раскрывайте («т. е.» → «то есть»). Аббревиатуры пишите так, как их произносят:
  «эм-ка-ад», «ВэТэБэ» или «ВТБ» (проверить на слух).
- Латиницу и бренды пишите кириллицей, как произносят, или через проверенную IPA в словаре:
  `pronunciation/lexicon.json`.
- Ставьте «ё» везде, где она есть: «всё», «её», «берёт».
- Омонимы с разным ударением («за́мок/замо́к», «кру́жки/кружки́») разводите через IPA с `context`.
- Длинные периоды с тремя придаточными разбивайте пунктуацией: точкой, тире или многоточием.

## Книга: правила атрибуции

1. Авторские слова («сказал он») читает рассказчик. Возврат к реплике после ремарки — тот же персонаж.
2. Чередование реплик без ремарок проверяйте по смыслу: обращения, ответы, грамматический род.
3. Курсив в исходнике (поле `note: курсив…`) часто означает мысли, письма или иностранные слова.
4. Рассказчик всегда без style: тембр задаёт голос. **[проверено]** Так рассказчик меньше дрейфует.
5. Безымянным эпизодическим ролям давайте ID `EP_…`. Разным людям в одной сцене нужны разные профили:
   `vox check` это проверит.
6. Не меняйте слова автора. Опечатки и сознательные правки оформляются полем `edit: "причина"`.
7. confidence честно: high — названо в тексте, medium — понятно из контекста, low — догадка.
   Блоки medium и low попадают в `attribution/REVIEW.md` для человека.

## Реклама, слоганы, рилсы

**Темп.** Спокойная русская речь — примерно 2–2,5 слова в секунду, энергичная реклама — 2,5–3.
Ролик 15 с — 30–40 слов, 30 с — 65–80 слов, 6-секундный бампер — 10–14 слов. Проверяйте по длительности
готовых дублей в `out/<сценарий>/index.md`.

**Структура короткого ролика:** хук в первые 1–2 секунды (вопрос, неожиданный факт) → польза →
доказательство → призыв к действию с названием бренда и простым следующим шагом.

**Практика:**
- Делайте 3 дубля (`takes: 3`): модель каждый раз играет по-разному, лучший выбирается на слух.
- Название бренда проверьте отдельно через `say` и закрепите произношение в словаре.
- Для диалоговой рекламы используйте блок со `speakers: [Аня=Kore, Олег=Puck]`, перехваты и `|угу|`.
- Громкость под соцсети — пресет `social` (−14 LUFS, пик −1 dBTP), он стоит по умолчанию для клипов.
- Субтитры `.srt` рядом с файлом расставлены приблизительно (пропорционально длине фраз). Для монтажа
  сверьте их с дорожкой или переснимите таймкоды через ASR.
- Музыку и звуковые эффекты накладывайте в видеоредакторе. Голос под музыкой обычно держат на 10–15 дБ
  громче подложки.
