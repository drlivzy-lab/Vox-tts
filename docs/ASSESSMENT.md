# Оценка харнесса: качество, доверие агенту, что улучшать

Дата: 21.10.2026. Оценка версии v2; раздел 6 — улучшения v3 (версия 0.3.0).

## 1. Итог в трёх строках

- Механика (кэш, журнал, лимиты, релизы, сборка, громкость) надёжна и закрыта тестами; агенту
  её можно доверять без присмотра: опасные шаги требуют `--yes` и сами себя ограничивают.
- Смысловая часть (кто говорит, с какой подачей, как ударять имена) — уровень сильного
  ассистента, не финального редактора: нужна выборочная проверка человеком и прослушивание.
- Харнесс ни разу не отправлял запрос в реальный API. Первый прогон — пилот на одной главе или
  трёх клипах с бюджетом в несколько центов, только с вашего разрешения.

## 3. Насколько можно доверить агенту

| Работа | Доверие | Что делает человек |
|---|---|---|
| ingest, draft, check, freeze, plan, assemble, master | высокое | ничего; смотрит итоговую сводку |
| Атрибуция ясных диалогов (двое, ремарки с именами) | высокое, ~95 % | выборочно 1 сцену из 10 |
| Атрибуция сцен с 3+ участниками, местоимениями, перебивками | среднее, ~80–90 % | читает REVIEW.md (блоки с низкой уверенностью) |
| Подача (style, теги) | среднее | слушает пилот, правит словарь подачи в BOOK_NOTES.md |
| Ударения и имена | низкое без уха | слушает `pron trial`, ставит accepted |
| Рекламные тексты и слоганы | среднее | выбирает дубль; агент даёт 3–4 варианта подачи |
| QC: accept/reject | среднее | спорные случаи (`qc` пометил, но агент не уверен) слушает сам |
| Платные запуски | только с вашего «да» | подтверждает план и бюджет |

Правило, которое стоит закрепить: агент может всё, что обратимо и бесплатно; всё, что стоит денег
или звучит в финале, проходит через план и ваше прослушивание выборки.

## 4. Что уже сделано в v2

- `.env` с `GEMINI_API_KEY` (порядок: переменные окружения → `.env` проекта → `.env` харнесса).
- `tts.py` — самостоятельный скрипт: один голос или диалог, все параметры API, без `--yes`
  только показывает запрос.
- Режим `clips` (`vox.py init --kind clips`) и `vox.py say`: слоганы, реплики, реклама, рилсы;
  дубли, форматы wav/mp3/m4a/opus/flac, пресеты громкости, SRT.
- Диалог двух студийных голосов одним запросом (Interactions API, `conversational`).
- Дословный QC: GigaAM-v3 (локально, MIT) + Gemini 3.8 Flash (облако, транскрипт + аномалии),
  запасные faster-whisper и vosk.
- `qc splices`: проверка склеек после монтажа; пресеты громкости и замер результата.
- `vox next` — следующий шаг с готовой командой; `vox show-job` — точный payload.
- Атрибуция: уверенность, доказательство, правка текста для CAPS/ё/тегов, BOOK_NOTES.md,
  курсив из FB2/EPUB как подсказка мыслей, REVIEW.md.
- Документы: AGENTS.md, GEMINI_TTS.md, SCRIPT_GUIDE.md, MONTAGE.md, QC_ASR.md.

## 5. Модель для дословного прослушивания

1. **GigaAM-v3 CTC** (Сбер, `ai-sage/GigaAM-v3`, MIT) — основной. CTC-декодер не «додумывает»
   текст, поэтому повторы и обрывки слов остаются в транскрипте; лучший открытый русский ASR,
   работает на CPU, на GPU быстро. Минус: без пунктуации и с ошибками на редких именах.
2. **Gemini 3.8 Flash** с промптом стенографиста (`vox/asr.py`, `VERBATIM_PROMPT`) — второй
   слушатель: даёт дословный текст и отдельный список аномалий (заикание, повтор, обрыв, шум,
   «чужой» голос). Стоит денег, поэтому включается для сомнительных запросов или выборки.
3. faster-whisper large-v3 — запасной; Whisper склонен сглаживать повторы, промпт частично
   помогает. vosk — офлайн-минимум.
4. CrisperWhisper (nyralabs) специально обучен на дословность, но лицензия некоммерческая —
   для рекламы компании не подходит.

## 7. Известные ограничения

- Реальный API не вызывался; форма запросов сверена с документацией Google и рабочим кодом WB.
  Особенно это касается файловых пакетов Batch (Files API) — первый запускать на 3–5 запросах.
- Нарезка групп ремарок опирается на паузы между строками. Если модель склеит строки без паузы, группа
  перегенерируется (`qc reject`); если так часто — выключите `group_remarks` для книги.
- Тариф `priority` для TTS не проверен; по умолчанию `flex`/`batch`.
- Диалог одним запросом — только два студийных голоса (ограничение API).
- Субтитры по GigaAM точны в пределах окна ≤ 20 с; самые точные — с faster-whisper (время каждого слова).
- Затраты — оценка по прайсу из `book.toml`; точные суммы в биллинге Google.
- Старые папки `harness\audiobook\` и `harness\books\` от v1 на диске не используются, их можно удалить.
