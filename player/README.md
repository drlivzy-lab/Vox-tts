# Плеер аудиокниг «Между строк» 2.0

Веб-приложение (PWA) для прослушивания книг, озвученных харнессом. Чистый HTML/JS без зависимостей и сборки,
работает как обычная статика: nginx, любой хостинг с HTTPS или `node server.mjs` для проверки.

## Что умеет

- **Библиотека книг.** Каталог `library.json` + папка `books/<id>/` на каждую книгу. Новая книга появляется
  в плеере сразу после выкладки, пересобирать приложение не нужно. Карточка «Продолжить» открывает последнюю книгу.
- **Тёмная тема с высоким контрастом** (по умолчанию), светлая для яркого солнца и «как в системе».
  Размер текста и кнопок: обычный / крупный / очень крупный.
- **Режим «Авто»** (кнопка в шапке плеера): кнопки до 128 px, лишнее скрыто, экран не гаснет.
  Тап по обложке — пауза, свайп влево/вправо — перемотка. Всё управление помещается в 800×480 без прокрутки.
- **Громкость 50–200 %** с лимитером (не хрипит на пиках) и **«Выравнивание для дороги»**: компрессор
  подтягивает тихие реплики к громким. Пока громкость не выше 100 % и выравнивание выключено, звук идёт напрямую,
  как в обычном плеере. На iPhone усиленный звук может прерываться на заблокированном экране — плеер предупреждает.
- **Таймер сна**: 15/30/45/60/90 мин или «до конца главы», плавное затухание; после остановки по времени
  плеер отматывает 15 секунд назад.
- **Закладки** одним нажатием, с подписью (удобно отмечать брак озвучки для исправления в харнессе).
- Перемотка 10/15/30/60 с, кнопки предыдущей/следующей главы, «Вернуться» после случайного перехода.
- Скорость 0,5–3× с шагом 0,05 без изменения высоты голоса.
- Кнопки на руле и экран блокировки (Media Session). ⏮ ⏭ на руле перематывают на шаг, а не на целую главу.
- **Офлайн**: скачивание книги частями по 4 МиБ с проверкой SHA-256 и докачкой; список скачанного с удалением.
- Позиция, скорость и закладки хранятся на устройстве для каждой книги. При выходе нового мастера с другими
  таймингами позиция переносится в ту же главу на ту же долю. Перенос прогресса между устройствами — файлом
  (Настройки → «Сохранить прогресс в файл» / «Загрузить»).
- Обновление плеера не обрывает прослушивание: появляется плашка «Обновить», страница перезагружается только по нажатию.
- Клавиатура: пробел/K — пауза, ←/→ или J/L — перемотка, PageUp/PageDown — главы, B — закладка.

Минимальные браузеры: Chrome/Android WebView 80+, Safari/iOS 15.4+, Firefox 100+.

## Как книга попадает в библиотеку

Готовый мастер харнесса публикуется командой `vox publish` (из корня репозитория):

```powershell
# книга из проекта харнесса (после `vox master`)
python -X utf8 vox.py --book projects\<книга> publish --library ..\library --cover обложка.jpg

# любой готовый M4B/M4A/MP3 с главами из chapters.ffmeta или manifest.json
python -X utf8 vox.py publish --library ..\library --m4b книга.m4b --chapters chapters.ffmeta `
    --id kniga --title "Название" --author "Автор" --cover обложка.jpg
```

Дополнительно: `--image key=путь|Подпись` (иллюстрация), `--cue key@1` (показывать во время главы 1;
`key@-1` — последняя глава, `key@3..5` — диапазон глав, `key@12.5-80` — секунды), `--version-label`,
`--narrator`, `--description`, `--link` (жёсткая ссылка на аудио вместо копии).

Структура библиотеки:

```
library/
  library.json                 список книг
  books/<id>/book.json         главы, хеши частей, иллюстрации
  books/<id>/book.m4b          аудио
  books/<id>/cover.jpg …       обложка и иллюстрации
```

## Проверка на компьютере

```powershell
python -X utf8 player\tools\make_demo.py            # демо-библиотека в player\library (синтетический звук)
node player\server.mjs --library player\library     # http://localhost:4173
node player\server.mjs --library ..\library --lan   # с телефона в той же Wi-Fi сети
cd player; npm test                                 # автотесты (Node 20+)
```

Офлайн-загрузка и установка на главный экран работают только по HTTPS (или на `localhost` самого устройства).

## Выкладка на сервер

```powershell
python -X utf8 player\tools\build_site.py --library ..\library --out ..\site
```

Содержимое `site\` загружается в папку плеера на сервере (сейчас это подпапка `/listen/<секрет>/` сайта).
Требования к серверу те же, что раньше: HTTPS, `Content-Type: audio/mp4` для `.m4b`, `Accept-Ranges: bytes`
и ответы 206/416 на Range-запросы, JavaScript MIME для `.mjs` и `sw.js`, `sw.js` и `*.json` без долгого кэширования.
Все файлы — с правами на чтение для веб-сервера (`build_site.py` выставляет 644).

## Переход со старого плеера «Сокрушителя Войн»

Публикация с тем же id и меткой версии сохраняет прогресс слушателей и их скачанную копию:

```powershell
$wb = "C:\Users\Artem\Desktop\Озвучание книг"
python -X utf8 vox.py publish --library ..\library --id warbreaker-ru --version-label master-v3 `
    --m4b "$wb\production\master_v3\warbreaker.m4b" --chapters "$wb\production\master_v3\chapters.ffmeta" `
    --title "Сокрушитель Войн" --author "Брендон Сандерсон" --cover "$wb\book\assets\01-cover.jpg" `
    --image "map=$wb\book\assets\02-i_001.jpg|Карта Т’Телира" --image "table=$wb\book\assets\03-i_002.jpg|Таблица возвышений" `
    --cue map@1 --cue table@-1 --link
```

- Версия получится та же (`master-v3-f053490fbb3a`), поэтому позиция из старого плеера подхватится точно.
- Скачанные в старом плеере части переносятся в новый кэш по SHA-256, повторно качать 675 МБ не нужно.
- Новый service worker при обнаружении старого включается сразу, без «Обновить»: старая страница этого не умеет.
- Старый адрес аудио `audio/warbreaker.m4b` стоит оставить на сервере на пару недель (можно жёсткой ссылкой на
  `books/warbreaker-ru/book.m4b`), чтобы не оборвать книгу тем, у кого открыта старая вкладка.
- Перед выкладкой — резервная копия текущей папки плеера вне публичного каталога, как при прошлых обновлениях.
